# Index

- **What this is:** the client's pocket instance of the SaaS marketplace — one React Native app (iOS + Android) carrying the same browse → evaluate → book/buy → manage journey as the site, rebuilt native: gestures, haptics, push, offline. Same API, same collections contract, same envelope; zero business logic on the device.
- **The same funnels, native:** the fulfillment archetypes drive the booking flows exactly as on the web — calendars for date-range types, session/seat pickers for timed-slot, carts for stock, instant delivery for digital, requirement forms for gigs, enrollment for courses, document upload for applications — one checkout spine, archetype steps composed on, states rendered truthfully from the saga.
- **Offline is the differentiator:** browsing serves from the persisted cache instantly; the client's own world (orders, bookings, tickets, enrolled content) is available offline by design; writes queue and reconcile; airplane mode shows a working app with honest pending states — the reason the app exists beyond the site.
- **Push is a product channel:** booking state transitions, payment confirmations, messages, and vendor updates arrive as notifications deep-linking into the exact screen with the stack correct — the saga's webhook-driven transitions are what the user feels as "the app told me instantly".
- **Sessions and identity:** tenant-bound tokens in secure storage, biometric unlock where the platform offers it, multi-account switching if the product declares it — resolution mirrors the API's tenant rules always.
- **The native bar:** 60fps feeds of media-heavy items, platform-correct navigation, payment sheets through the native rails where available (through the payment port's mobile drivers), media upload pipelines for reviews/requirements.
- **What "done" means here:** cold start to browsable content under two seconds on a mid-range Android, the funnel completes offline-interrupted without losing the user, crash-free rate watched per rollout, typecheck/lint green and both store builds passing.
