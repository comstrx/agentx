# Index

- **What this is:** the operations cockpit for the SaaS core — one Next.js admin panel serving every non-client actor (super, admin, vendor, affiliate, delivery) of every tenant, driven entirely by the API's permission payload. One codebase, every panel: what an actor sees is what their permissions render.
- **The dynamic-panel architecture:** actor systems (`systems/super`, `systems/admin`, shared) resolve behind a catch-all segments route — screens are declared resource surfaces materialized by the table/form/detail/stats engines, not hand-built page trees. Adding a resource to the panel is a declaration (columns, fields, actions) wired to the API's collections contract.
- **Permission-driven to the pixel:** the `can(permission)` gate wraps every menu entry, route, column, field, and button; settings locked by a higher authority render faded with their lock. The ~200-page surface exists once; permissions carve each actor's slice — `if panel == 'vendor'` never appears.
- **The data contract:** the API's `routes/collections/` mirror is the source of endpoints, headers, and shapes; tables page/filter/sort through the API's bounded DSL one-to-one; mutations return the envelope whose field errors map inline. The panel holds zero business logic — it renders state machines, it never re-implements them.
- **The working set:** admin-dense screens — gated tables with saved views and bulk actions, form engine mirroring server validation, detail tabs derived from relations, dashboards from the statistics endpoints, realtime badges over the socket lane, wallet/ledger views that render the money trail honestly.
- **Tenancy in the client:** tenant resolution rides the API's domain rules; the super's cross-tenant context switch is an explicit, visible mode — never an ambient default.
- **What "done" means here:** the actor sees exactly their permission slice, every surface speaks the interaction grammar (list → detail → edit → confirm), typecheck/lint/build green, and a permission change reshapes the panel with zero code.
