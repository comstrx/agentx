# Stack

The locked toolchain of this panel — pre-approved by operator decision; verify versions in the lockfile, then obey. Substitution is refusal-with-reasons, never improvisation.

- **The spine:** Next.js (App Router, Turbopack, `proxy.ts` edge) · React + React Compiler (`reactCompiler: true` — never remove; manual `useMemo`/`useCallback`/`memo` are FORBIDDEN, the compiler owns memoization) · TypeScript strict · Tailwind v4 CSS-first (`globals.css` `@theme`; NO `tailwind.config.*` — never create one) · pnpm only.
- **State split, absolute:** TanStack Query v5 = ALL server state (the panel runs query-cache-first mode) · Zustand v5 = ephemeral UI state only (sidebar, palette, transient selections) · Zod v4 = every external boundary (API responses, forms, env) — server data in Zustand or a Zod-less fetch are the two canonical violations.
- **Components:** shadcn/ui generated over Base UI primitives — add via the shadcn CLI only, never hand-copied from docs of the radix era. `components/ui/**` is REGISTRY-OWNED: CLI-managed, lint-fix only, never re-spaced, never hand-written — house composites live in `components/custom`, which also wraps every third-party widget behind a house face.
- **The capability roster, one library per job:** react-hook-form + Zod resolvers = all forms (through the shadcn Form recipe) · TanStack Table + Virtual = tables · Recharts via shadcn Charts = charts · Motion + native View Transitions = animation · next-intl = i18n/RTL · next-themes = scheme switching · cmdk = command palette · dnd-kit = drag & drop · react-dropzone = the upload primitive · Embla = carousels · sonner = toasts · lucide = the ONE icon set.
- **Named escalations, operator approval required before installing:** Pragmatic DnD (1000+ draggables) · Uppy + tus (resumable uploads) · ECharts (>10k points or realtime charts) — the trigger condition is written; hitting it is a conversation, not a `pnpm add`.
- **Identity is backend-owned:** sessions are httpOnly cookies the API sets; the panel consumes `/v1/auth/*` through the same endpoint registry as everything else and runs NO auth server of its own — a token touched by client JS is a violation, not a convenience.
- **Biome is lint + import order only; the formatter is retired by design** — never re-enable it, never fight the hand style with a tool; `// biome-ignore` is a gate bypass and banned like every suppression.
- **The gate:** `pnpm check` (biome) · `pnpm typecheck` · `pnpm test` (vitest) · `pnpm build` when routing/config/deps move — the `verify` script runs the full chain; a change that only works in dev is not done.
- Env discipline: typed env parsing in `lib/env` (Zod-validated at boot), `NEXT_PUBLIC_*` exposures individually reviewed, `.env.example` maintained in the same change as any new variable.
