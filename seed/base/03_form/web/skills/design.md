# Design

Building the design system that makes every screen look expensive — engineering, not decoration.

- **Tokens are the system's DNA, layered in two tiers:** primitives (the raw scales: color ramps, spacing steps, type sizes, radii, shadows, durations/easings) → semantic tokens (`surface`, `surface-raised`, `text-muted`, `border-subtle`, `accent`) that components consume — a component never touches a primitive; a rebrand edits primitives, a redesign edits semantics, components move for neither.
- **Dark mode is a token remap, verified per component:** semantic tokens re-resolve per scheme (shadows weaken, borders strengthen, elevations become surface shifts) — a component built on semantics is dark-ready by construction; every primitive gets a visual check in both schemes before it ships, because "works in dark" is not derivable from code review.
- **The type scale is a ratio, not a collection:** one base size, one scale ratio, few weights — line heights per size step, measure (line length) capped for reading surfaces; Arabic/RTL scripts get their line-height and font-stack decisions made deliberately (Latin metrics choke Arabic ascenders), not inherited by accident.
- **Spacing is rhythm on one scale:** every gap, inset, and stack step comes from the spacing scale — mixed arbitrary values are why a page "feels off" without anyone naming it; density variants (comfortable/compact) are a scale swap, not per-component padding surgery.
- **Color is a system with math:** ramps built for contrast (each step's role known: bg, hover, border, text-on), interactive states derived (hover/press/focus/disabled from the same ramp), and every text/surface pair passing contrast in BOTH schemes — checked by tooling in CI, not by squinting.
- **Elevation tells a story:** a small fixed set of levels (flat, raised, overlay, modal) with consistent shadow/surface treatment per scheme — ad-hoc shadows are visual noise; z-index rides the same scale so stacking is never a lottery.
- **Motion is tokenized like color:** duration steps (instant/fast/base/slow) + easing tokens (enter, exit, move) consumed by every animation — micro-interactions (press, hover, focus, enter) live in the primitives so features inherit them; `prefers-reduced-motion` collapses to opacity-only at the token layer, once.
- **Variants are the only appearance API:** size/tone/emphasis declared as variant maps on primitives — the axes multiply (a `danger ghost small` button falls out for free); boolean-prop styling and className overrides seen twice become variants, keeping every exception on the record.
- **The system ships with its own gallery:** every primitive rendered in all variants × states × schemes on one internal page — the regression surface for redesigns, the vocabulary page for builders, and the fastest UI review ever shipped.
- Consistency is the luxury signal: one icon set, one illustration voice, one radius personality, one focus-ring treatment — users read coherence as quality before they read any single screen as pretty.
