# Api

- **One envelope, never a second shape.** All output flows through `BaseResource` / `App\Support\Response`: success → `{ status: true, data, …extra }`, fail → `{ status: false, message, errors }`. Surface: `Response::success($data, $status, $extra) · ::message($text) · ::fail($errors, $status, $msg) · ::error($key, $msg, $status) · ::noContent()`.
- **Stateless Bearer tokens everywhere** (Sanctum): no SPA cookie mode — it breaks with custom domains. Every token is bound to a tenant; middleware asserts `token.tenant == domain.tenant`. Tenant resolution = subdomain + token, both must agree.
- **Validation is mandatory on every write:** a FormRequest at the boundary — types, sizes, whitelists, `uuid` rules on ids. Inside the boundary, input is trusted; the repository's `fields()` is the only door to storage, undeclared input never lands.
- **Authorization is server-authoritative RBAC:** `has:<permission>` middleware gates the action, the scopes thread gates the rows, `fields()` gates the columns. Client-supplied roles/permissions are display hints, never decision inputs. Fail closed at all three gates.
- **Idempotency keys on financial and mutation-sensitive endpoints** (`Idempotency-Key` header, enforced via the lock/request Support domains); duplicate delivery is a certainty — design for replay, not hope.
- **The filter DSL is bounded:** `column@op` (in, notin, between, like, ranges) and sort are `hasColumn`-guarded against the declared map — an unknown column or relation is rejected, never passed to SQL. Search is whitelisted; page size is capped; pagination is keyset on growing sets.
- Errors carry a stable machine key + human message and never leak internals (SQL, traces, paths). `Locale` header drives translated messages; translations are keys, never hardcoded strings.
- **Response vocabulary lives as backed enums, never literals:** one `ApiCode` enum (the machine keys: `ok`, `validation`, `forbidden`, `conflict`, `throttled`, …) + one `Msg` enum (the human-message catalog: `INVALID_STATE`, `OUT_OF_STOCK`, `INSUFFICIENT_BALANCE`, … — localization keys in disguise) — every `Response::fail`/`::error` call site speaks enum cases; a raw string key or message typed inline is the drift the enums exist to kill, and adding a failure class means adding a case, which the type system then tracks everywhere.
- Response shaping lives in Resources only — a service returning transport-shaped arrays has leaked a layer.
- Versioning by prefix (`/v1`); breaking response changes require a new version or an additive shape — the collections mirror is the contract of record and updates in the same change.
