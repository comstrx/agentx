# Support

- `app/Support/` is the project's private std-lib. First level = **folders only**, never loose files. Each folder's `index.php` is the public facade — `support/str/index.php` → `namespace App\Support; class Str` — and internal PascalCase siblings (`namespace App\Support\Str;`) hold the pieces. Even a one-file helper becomes `folder/index.php`.
- **Zero business logic in Support — absolute.** Native and infrastructure power only; the moment a business noun appears, the code belongs in a trait or service.
- Canonical domains (created on demand, this map is the naming contract, not a build list): `arr · cache† · cast · context · database · date · event† · file · http · json · lock† · log · mail · net · num · parse · queue† · request · response · security · storage† · str · throttle† · validate`.
- **`†` = swappable adapter — the house anatomy:** `index.php` facade + **`Adaptor.php`** (the interface/abstract — the house name, not `Driver`) + concrete adaptors named for their backend bare (`Redis.php`, `Memory.php`, `Stripe.php`, `Paximum.php`). The facade holds a static cached adaptor + a `$drivers` class map and selects by the **ports config** (`config('context.ports.<domain>')`) — adding/replacing a backend = one adaptor file + a map entry + config; the facade also accepts an injected adaptor for tests. Callers never name a concrete backend; keep the neutral surface even with one backend.
- **The cache DSL is tags-first and tenant-scoped structurally:** every operation takes tags the facade's `scope()` prefixes with the tenant (`t{id}:{tag}`) — invalidation is `forget(tags)`, never key archaeology; `rememberLocked` (per-key lock recompute) is the stampede guard built into the surface; `lock(name, seconds, callback, fallback)` is the one distributed-lock door.
- **The `folder/index.php` layout cannot PSR-4-resolve — read `composer.json` for the project's mechanism before adding files:** either classmap entries (new file ⇒ `composer dump-autoload` or it will not resolve) or a registered `Support/autoload.php` spl shim in `autoload.files` mapping `App\Support\X` / `App\Traits\{Dna,Util}\X` → `X/index.php` (new files resolve immediately, internal siblings stay PSR-4-shaped). Never add a competing PSR-4 rule to "fix" the layout.
- **Facade shadowing is intentional:** `Str`, `Arr`, `Cache`, `Date`, `Log`, `Mail`, `Queue`, `Storage`, `Http`, `Request`, `Response`, `Context` deliberately shadow Illuminate equivalents — prefer ours. When a file genuinely needs both, import both and alias the Illuminate one (`use Illuminate\Support\Str as IlluminateStr;`) — never fully-qualify inline.
- No class name may be a reserved keyword: `Boolean` not `Bool`, `Casing` not `Case`, `Matches` not `Match`, `cache/Tag` not `Index` (collides with `index.php`).
- Key guarantees enforced here once for everyone: `log/Redact` (secrets never logged), `net/Ip` (SSRF guard on outbound HTTP), `num/Money` (integer minor-units math only), `security` wraps vetted crypto — no DIY primitives.
- Support grows with the project: a feature needing a missing capability **adds it here** (named well, right domain), then calls it — the pipeline law's other half.
