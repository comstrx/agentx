# Operations

The artisan command layer — declared truth, derived truth, and drift all get machinery.

- **The sync/verify/reconcile triad is the law of derived state:** every subsystem that seeds from declarations or denormalizes (the permission genome, gateways, providers, settings, counters, geo trees, levels, journeys) ships up to three commands — `x:sync` (idempotently author the declared truth into rows), `x:verify` (assert invariants, exit non-zero, CI-runnable), `x:reconcile` (repair measured drift). A denormalization without its verifier is a silent-corruption generator.
- **Verify commands are the test suite for DATA:** wallets balance to their ledgers, order totals re-derive, permission rows match the genome, counters match counts, every stored stage is reachable in its machine — table output, per-tenant loops, honest exit codes; scheduled AND runnable on demand when support asks "is this tenant sane".
- **Sync is idempotent authoring:** declared truth upserts by natural key — re-running is a no-op; sync never deletes what humans authored, it reports strays and lets verify flag them. Sync writes, verify judges, reconcile repairs — a command doing two of the three is two commands.
- **The generator command is the engine's front door** (`new:model`-shaped): a fields DSL + options emit migration, model, repository, service, controller, resource, request wired to the engine — never overwriting existing files, always producing declarations that pass the gate untouched. Scaffold output that needs hand-editing is a bug in the scaffold.
- **The API contract has two machine surfaces, both generated:** the `routes/collections/<panel>.json` mirror built by the collection command from the route table + request metadata, and a live `GET /v1/contract` endpoint rendering codes, message catalog, and envelope straight from the enums — the frontend consumes both without meetings; hand-editing either is drift.
- **Scheduling lives in `routes/console.php`** on the modern skeleton: reconcilers, sweepers, subscription renewals — every entry `onOneServer()` + `withoutOverlapping()`, tenant-aware where it iterates, chunked where it walks.
- **Commands restore context like requests do:** tenant loops set/reset the tenant context per iteration through the same accessor middleware uses — a command writing rows without tenant context is the bulk version of the cross-tenant leak.
- Long work reports as it runs: chunked walks, per-tenant progress, a one-line summary an operator can paste into an incident thread — a command that prints nothing is a command nobody trusts under pressure.
