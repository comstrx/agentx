# I18n

- **Every user-facing string is a key from day one:** messages live in locale files (namespaced per feature), resolved through the i18n layer (next-intl-shaped) — a hardcoded human string in JSX is a defect, not a shortcut; retrofitting i18n costs 100× declaring it.
- **The locale is routing state:** locale-prefixed segments (or domain mapping) resolved once in the proxy/middleware, flowing through the request — server components read it from the request context, client components from the provider; TWO sources of locale truth is a hydration mismatch factory.
- **RTL is a first-class layout mode, not a patch:** `dir` set at the html root from the locale · logical properties everywhere (`ps-4`/`pe-4`, `start`/`end` — never `pl-4`/`left` in shared components) · directional icons (arrows, chevrons) flip via the one icon wrapper · carousels, steppers, and slide motions mirror — a component reviewed only in LTR is half-reviewed.
- **Translations carry structure, not fragments:** ICU messages with plurals, gender, and interpolation (`{count, plural, …}`) — string concatenation of translated fragments produces grammar that no locale survives; the key's value is a full sentence with holes, never sentence parts glued in code.
- **Formatting flows through the i18n layer, always:** dates, numbers, money, relative time via the locale-aware formatters (one wrapper module) — `toLocaleString` scattered raw or hand-formatted dates fork the formatting truth; Arabic-Indic vs Latin digits is a per-locale product decision made ONCE in the wrapper.
- **Server-rendered means locale-rendered:** SSG/ISR pages generate per locale (locale in the static params), metadata/OG localized per page, `hreflang` alternates generated from the routing map — a localized product whose SEO speaks one language left half its market unindexed.
- **Keys are contracts with hygiene:** stable names (`feature.section.action`), no orphans (unused keys pruned), no missing (CI check: every key referenced exists in EVERY locale, fallback locale declared) — a missing-key leak renders `feature.checkout.confirm` to a paying customer.
- **Fonts and type per script:** the font pipeline loads per-script subsets (Latin + Arabic stacks defined together), line-heights tuned per script (Arabic ascenders choke Latin metrics), and the type scale verified in both — the design system's obligation, wired here.
- **Client bundles carry only their namespace:** messages split per feature/route, the client receives its slice — shipping the whole catalog to every page taxes LCP in every language at once.
- Pseudo-locale testing in dev: an accented/expanded pseudo-language flushes out unexternalized strings, truncation-hostile layouts, and concatenation bugs before any translator is hired — cheap, automated, merciless.
